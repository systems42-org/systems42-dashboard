Repository configuration (_system/wiki.yaml)

The dashboard expects a Systems42 derivative repository containing wiki/, raw/, _system/metamodel/, _system/anchors/ and _system/wiki.yaml. All dashboard settings live in _system/wiki.yaml:

Key Purpose Example
system_name Displayed in the hero and browser title. "My System"
tagline Short fallback line when no vision sentence exists. "Requirements and architecture"
dashboard_version Pinned release tag (quoted) or local in the dashboard repo. "{{ version }}"
brand Shipped default (systems42) or a folder inside your repository. brand/
intro Switches the brand intro animation on or off. on or off
about Optional Markdown page under docs/ shown at /about. docs/brand/README.md

Branding by configuration

Every Systems42 wiki uses the same released dashboard image and applies its own identity through a folder in its repository (for example brand/):

  • mark-dark.svg (or .png) and mark-light.svg for dark and light themes.
  • favicon.svg (or .png) for browser tabs.
  • Optional intro.html: runs inside a sandboxed iframe without access to wiki pages or network, finishes within two seconds, and respects reduced motion.

If a brand folder is missing or incomplete, the dashboard falls back to the shipped systems42 brand without showing an error.

Workshops & shared sessions

  • Start the dashboard on the facilitator's laptop with ./dashboard.sh up (or make dev).
  • Participants scan the QR code on the home page (or project /join) to open the same wiki on their phones or laptops with zero installation.
  • The first browser tab to connect becomes the Keyholder ("Yoda") and controls the temporary View dialog and Disconnect all.
  • Closing the last open tab stops the container automatically.

Read-only & security scope

The dashboard mounts your wiki read-only and never writes files into your repository. Because it has no login and serves the local network in workshop mode, run live sessions only on trusted networks. For public read-only publishing, use the static site export (make site).
