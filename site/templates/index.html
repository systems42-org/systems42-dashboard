Start on your own Systems42 wiki in two minutes

Run natively with the macOS app or standalone Go binaries (no Docker, uv or Python), or use the thin launcher dashboard.sh with Docker or uv.

Native Go app & binaries (zero dependencies)

Install the universal macOS app from the release .dmg and pick any wiki folder from the menu bar, or run a static Go binary on Linux or Windows:

systems42-dashboard --open /path/to/your-wiki

One app opens any Systems42 wiki read-only, with no Docker, uv or Python required.

Download macOS app & binaries →

Pinned launcher (dashboard.sh for Docker or uv)

curl -fsSLO https://dashboard.systems42.org/downloads/dashboard.sh
chmod +x dashboard.sh
./dashboard.sh up   # Docker, or ./dashboard.sh uv without Docker

Reads dashboard_version: "{{ version }}" from _system/wiki.yaml and runs offline after the first pull.
