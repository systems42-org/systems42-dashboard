Start on your own Systems42 wiki in two minutes

Pin a dashboard release in _system/wiki.yaml, drop the thin launcher dashboard.sh into your repository, and run it with Docker.

1. Download the launcher

curl -fsSLO https://dashboard.systems42.org/downloads/dashboard.sh
chmod +x dashboard.sh

Pin the release in _system/wiki.yaml:

dashboard_version: "{{ version }}"
brand: systems42

2. Launch the dashboard

# With Docker (Linux & macOS, offline after first pull)
./dashboard.sh up

# Stop again
./dashboard.sh down
