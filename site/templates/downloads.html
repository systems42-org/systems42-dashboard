Quick installation snippets

Choose the option that fits your machine: macOS app, standalone binary, uv or Docker. Every step is in the install guide.

macOS Desktop App (.dmg)

Open Systems42-Dashboard-{{ version }}-universal.dmg, drag Systems42 Dashboard.app into Applications, and launch it. Pick any Systems42 wiki folder from the menu bar or drop a folder onto the app icon.

The app is ad-hoc signed (not Apple-notarised). After downloading via a browser, approve it once in System Settings → Privacy & Security → Open Anyway, or clear the browser quarantine flag in a terminal:

xattr -dr com.apple.quarantine "/Applications/Systems42 Dashboard.app"

Downloading with curl avoids the browser quarantine flag altogether:

curl -fsSLO https://github.com/systems42-org/systems42-dashboard/releases/download/v{{ version }}/Systems42-Dashboard-{{ version }}-universal.dmg

Standalone Go binary (Linux & Windows)

tar -xzf systems42-dashboard-{{ version }}-linux-amd64.tar.gz
./systems42-dashboard --open /path/to/your-wiki

Pass --port 0 to pick any free port or --check /path/to/your-wiki to run the Systems42 layout check. Works offline with zero external runtime.

Install launcher via curl (Docker or uv)

curl -fsSLO https://dashboard.systems42.org/downloads/dashboard.sh
chmod +x dashboard.sh
./dashboard.sh up   # Docker, or ./dashboard.sh uv without Docker

Update to the newest published release later with ./dashboard.sh update.

Minimal _system/wiki.yaml

system_name: "My System"
tagline: "Requirements and architecture wiki"
brand: systems42
intro: on
dashboard_version: "{{ version }}"

Quote the version string so YAML keeps "0.10.0" as text instead of a number.

Supported platforms & scope

Run with Docker or uv on Linux and macOS, with the universal macOS desktop app (macOS 14+), or with standalone Go binaries on Linux and Windows. All variants read your wiki strictly read-only, share full route parity, and run offline after install. Read the Go Dashboard Requirements Summary for design details and trade-offs.
