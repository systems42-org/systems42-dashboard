Quick installation snippets

Copy into any Systems42 derivative repository.

Install launcher via curl

curl -fsSLO https://dashboard.systems42.org/downloads/dashboard.sh
chmod +x dashboard.sh
./dashboard.sh up

Update to the newest published release later with ./dashboard.sh update.

Minimal _system/wiki.yaml

system_name: "My System"
tagline: "Requirements and architecture wiki"
brand: systems42
intro: on
dashboard_version: "{{ version }}"

Quote the version string so YAML keeps "0.10.0" as text instead of a number.

Supported platforms & scope

Supported on Linux and macOS with Docker. After the first start with network access, the dashboard runs fully offline. It is built for local reading and trusted workshop rooms, with no login and no write access to your wiki.
