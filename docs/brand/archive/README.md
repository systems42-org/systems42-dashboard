# Archived brands

`chart/` holds the Chart mark, the dashboard's shipped brand from 2026-11-23 to 2026-11-26, when the helix replaced it. It is a complete brand folder: marks, favicon, intro and the brand page with its lockups.

To use it in a wiki, copy `chart/` to the wiki's `brand/` folder and set `brand: brand/` in `_system/wiki.yaml`.
