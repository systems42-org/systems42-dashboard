# Domain term: Obsidian

Raised by Gernot Starke on 2026-11-22. Not yet captured into `wiki/`.

**Obsidian.** A note-taking program that edits a folder of Markdown files and links them with wikilinks. People use it to read and edit a Systems42 wiki. The dashboard reads the same files and follows Obsidian's syntax for links, aliases and callouts. It has no interface to Obsidian.

Homepage: <https://obsidian.md>
