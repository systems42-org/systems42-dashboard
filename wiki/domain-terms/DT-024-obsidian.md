# Obsidian

**Definition.** A note-taking program that edits a folder of [[DT-015-markdown|Markdown]] files and links them with [[DT-017-wikilink|wikilinks]]. People use it to read and edit a [[DT-002-systems42-wiki|Systems42 wiki]]. The [[DT-001-dashboard|dashboard]] reads the same files and follows Obsidian's syntax for links, aliases and callouts. It has no interface to Obsidian.

**Homepage.** <https://obsidian.md>
