# Dashboard

**Definition.** The read-only program that shows a [[DT-002-systems42-wiki|Systems42 wiki]] in a browser. It comes in three forms: a [[DT-025-docker|Docker]] image, a [[DT-027-uv|uv]] start and an app for macOS.
