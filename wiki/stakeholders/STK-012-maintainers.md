# Maintainers of the dashboard and the Systems42 method

**Snapshot.** `make sync` carries each of their changes into every project wiki. The tests that hold templates, metamodel and dashboard together exist for them. Builders of project-specific dashboards ([[STK-021-builders-of-project-specific-dashboards]]) depend on what they change.

**Goals.**
- Change the dashboard and the method without breaking existing project wikis.

**Concerns / pains.**
- Every change reaches every project wiki.

**Interactions.** None recorded yet.
