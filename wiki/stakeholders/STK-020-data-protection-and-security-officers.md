# Data protection and security officers

**Snapshot.** The dashboard has no login and listens on all network interfaces. Anyone on the same network who knows the address can read everything, and the home page shows a QR code. That is reasonable in a trusted room. It may not be for confidential requirements on hotel or customer Wi-Fi. See [[CON-001-proof-of-concept-not-production-ready]].

**Goals.**
- Know where the dashboard may safely be used.

**Concerns / pains.**
- Confidential requirements readable by anyone on the same network.

**Interactions.** None recorded yet.
